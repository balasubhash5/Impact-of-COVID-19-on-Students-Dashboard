# Impact of COVID-19 on Students Dashboard

## 📌 Project Overview
The **Impact of COVID-19 on Students Dashboard** is a Power BI project designed to explore how the COVID-19 pandemic affected students' academic activities, mental well-being, online learning, and lifestyle.

The project uses data visualization to present patterns and insights that help understand the challenges students experienced during the pandemic.

## 🎯 Objectives
- Analyze the impact of COVID-19 on students' education.
- Explore online learning experiences and academic challenges.
- Understand changes in students' mental health and daily routines.
- Present key findings through interactive Power BI visualizations.
- Support data-driven understanding of student experiences during the pandemic.

## 🛠️ Tools and Technologies
- **Power BI Desktop** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation, where applicable
- **DAX** – Measures and calculations, where applicable
- **Dataset** – Student survey data related to COVID-19

## 📊 Dashboard Features
- Interactive charts and visualizations
- Analysis of student experiences during the pandemic
- Educational and lifestyle impact analysis
- Visual presentation of key trends and patterns

*Note: The exact metrics and visuals depend on the dataset and report pages in the Power BI file.*

## 🚀 How to Use
1. Download or clone this repository.
2. Install Power BI Desktop.
3. Open `Impact of COVID19 on Students Dashboard.pbix`.
4. Explore the report pages, charts, filters, and slicers.
5. Interact with the visualizations to investigate the available data.
